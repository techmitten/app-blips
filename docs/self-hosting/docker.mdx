Docker runs AppBlips in a container, so you don't install Node.js or anything else. You build it with one command and use it in your web browser.

This is the same browser version you get when you [run AppBlips from source](/quickstart-source). If you only want to try AppBlips, [use it in your browser](/quickstart-browser) or install the [desktop app](/quickstart-desktop).

## Start AppBlips

<Steps>
  <Step title="Install Docker">
    On Windows or macOS, install and open [Docker Desktop](https://docs.docker.com/get-docker/). On Linux, install [Docker Engine](https://docs.docker.com/engine/install/) with the Compose plugin. On Ubuntu: `sudo apt install docker.io docker-compose-v2`.
  </Step>
  <Step title="Get the code">
    ```bash
    git clone https://github.com/techmitten/app-blips.git
    cd app-blips
    ```

    No Git? Open the [GitHub page](https://github.com/techmitten/app-blips), click **Code**, then **Download ZIP**. Unzip it and open a terminal in that folder.
  </Step>
  <Step title="Build and start">
    ```bash
    docker compose up -d
    ```

    The first build takes a few minutes. Later starts take seconds.
  </Step>
  <Step title="Open AppBlips">
    Go to [http://localhost:3000](http://localhost:3000) and follow the setup screens. You'll need an API key from an AI provider. See [Choose an AI provider](/ai-providers).
  </Step>
</Steps>

<Tip>
  Type `docker compose` with a space. The older hyphenated `docker-compose` can't read AppBlips' setup file.
</Tip>

Your projects and API key are saved in your web browser, not in the container. The container restarts by itself when Docker or your computer restarts, until you stop it.

## Everyday commands

Run these in the AppBlips folder.

- **See the logs** (useful if the page doesn't load): `docker compose logs -f`. Press `Ctrl+C` to stop watching. AppBlips keeps running.
- **Stop:** `docker compose down`
- **Update:** run `git pull` (or download and unzip the code again), then `docker compose up -d --build`. Your projects stay in your browser, so open the same address as before.

## Use another port

1. Create a file named `.env` in the AppBlips folder, or copy `.env.example` to `.env`.
2. Add a line with the port you want:

   ```bash
   APPBLIPS_PORT=8080
   ```

3. Run `docker compose up -d`.
4. Open `http://localhost:8080`.

<Warning>
  Your browser keeps projects separately for each address, so the new port starts empty. Before you switch, go to **Settings → Data → Export** at the old address. Then use **Settings → Data → Import…** at the new one.
</Warning>

## Give the server its own AI provider

You can put an AI provider in the same `.env` file. AppBlips then offers a **Free (no key needed)** option that uses it. For example:

```bash
OPENAI_API_KEY=sk-ant-...
```

Run `docker compose up -d` after you change `.env`. The [configuration reference](/self-hosting/configuration) lists every setting.

## Keep it private

`docker-compose.yml` publishes AppBlips on `127.0.0.1`, so only your own computer can open it.

<Warning>
  Keep the `127.0.0.1:` part. AppBlips has no sign-in, so anyone who can reach it can build with the key you gave the server. See [Security](/self-hosting/security#if-you-open-appblips-to-other-devices).
</Warning>
