Many requests AppBlips sends to your AI start with the same text. **Prompt caching** lets your provider remember that text, so it costs less and the AI starts answering sooner. It works automatically with every [supported provider](/ai-providers#supported-providers). You don't need to do anything.

## How it works

Providers measure text in **tokens** (about three-quarters of a word) and charge for the tokens the AI reads and writes. After reading a request, the provider keeps its opening text for a few minutes. If your next request starts with the same text, it reuses that and charges much less for it.

Caching only helps with text the AI **reads**. The code it **writes** is new each time and costs the usual price.

## What gets reused

- **The instructions.** Every build starts with the same detailed guidance for the AI.
- **Your home page.** When you build a multi-page website, each extra page is a separate request that includes your finished home page, so the pages match. Your provider reads the home page in full once and reuses it.
- **Earlier steps of an edit.** An edit often takes several steps, and each step resends the earlier ones.

Multi-page websites and multi-step edits save the most.

## Provider differences

- **OpenAI, Gemini, xAI and DeepSeek** cache on their own. AppBlips puts the shared text first so they can spot it.
- **Anthropic**, and **Claude models through OpenRouter**, only cache text marked for reuse. AppBlips adds the marks.

## Good to know

- **The cache lasts only a few minutes.** Steady work saves the most. After a break, the next request reads everything in full again.
- **Claude charges extra to save text.** The first time costs about 25% more than normal, and reads from the cache cost a tenth of the normal price or less, so it pays off on the first reuse. Other providers don't charge extra to save.
- **The token counter shows how much was cached, not what you saved.** Click the token counter to see how much input was read from the cache (**Cache reads**) or saved to it (**Cache writes**). It's an estimate, and it doesn't work out prices. Check your provider's usage page for what was cached and what you paid.
