There are two ways to change your app:

- **Ask in the chat.** Works in every studio. Describe the change and the AI makes it.
- **Click on the page.** Works in the Website studio. Edit text, swap pictures and move things yourself, instantly and with no AI.

Every change is saved as a version, so you can undo it with **Previous version** or Ctrl+Z (⌘Z on a Mac).

## Ask for a change in the chat

Type what you want different and send it. Plain words work best:

```
Move the Submit button to the bottom right and make it green.
```

The AI changes the app you have instead of starting again. For writing tips, see [Build an app from a prompt](/features/building-apps).

## Edit the page directly (Website studio)

Direct editing is off when you open a project, so clicks reach the page and its buttons and links work as they will for visitors. To edit, click **Edit Mode** in the preview toolbar. The key then reads **Editing**. Click it again to turn editing off.

While editing is on:

- **Click** any element to edit its text, swap pictures, or change links and colors.
- **Drag** any element to move it on the page.

Hover to see what you'd select, then click. On a computer, an editor bar floats at the bottom of the preview. When the preview is narrow, and on phones and tablets, a slim bar sits at the top with the tools along the bottom. Close the editor with Escape or **Close editor**.

### Edit text

Click a heading, paragraph or button label and type. For a link, double-click. A formatting bar offers font and size, **Bold**, **Italic**, **Underline**, **Uppercase**, alignment and **Text color**. To save, click **Done**, click elsewhere or press Ctrl+Enter (⌘+Enter). To discard, click **Cancel** or press Escape.

### Change a picture

Click a picture and use the editor bar:

- **Image URL:** opens a box where you paste a web address.
- **Choose from My images:** pick one from your project's [My images](/features/tools#my-images-beta).
- **Upload:** use a picture from your computer (up to 8 MB).
- **Width and height:** set the size in pixels. After an upload, **Fit size to image** keeps the width and matches the height to the new picture.
- **Alt text:** opens a box for a short description for screen readers, also shown if the picture can't load.

After **Image URL** or **Alt text**, click **Done** in the box, then **Apply** in the editor bar.

### Change links, colors and backgrounds

Depending on what you select, the editor bar offers:

- **Link:** type an address, or pick one of your pages or a `#section`. The arrow beside it opens the link in a new tab.
- **Fill:** a background color. It replaces a gradient if there was one.
- **Wallpaper:** upload a picture as a section's background.

### Select the section around something

To select the card or section around an element, click the select parent key in the editor bar. Click it again to go up another level.

### Move, copy and delete

The editor bar has keys for the selected element:

- **Move up** and **Move down** (Alt+↑ and Alt+↓, or ⌥↑ and ⌥↓ on a Mac).
- **Duplicate** (Ctrl+D, or ⌘D on a Mac). The copy doesn't repeat `id` attributes, so links still go to the original.
- **Delete** (Delete or Backspace).

### Drag to move

Press an element and drag it. A line shows where it will land. Let go to drop it, or press Escape to cancel. Near the top or bottom edge, the preview scrolls.

To move a container such as a card, select it first (for example using **Select parent**), then drag from inside it. Moved items stay part of the page's normal layout, so it still fits every screen. Words move with their paragraph, and list items and table cells stay among their own kind.

### Select several things

- **Drag a box** across empty page background to select everything fully inside it.
- **Shift+click** to add or remove one element.
- **Shift+drag** a box anywhere to add to your selection.

On phone and tablet views, dragging scrolls the page, so hold Shift to draw a box. You can select up to 40. Then describe a change and click **Apply with AI**, or press Delete to remove them all. Press Escape or click **Clear selection** to stop.

## The right-click menu

Right-click the page to open the menu. A blue line shows where anything you add will go.

If you right-click text or a picture, the menu can **Cut**, **Copy**, **Duplicate** or **Delete** it. Always available:

- **Paste:** puts the last cut or copied item at the blue line, on any page of the project. Cut and Copy don't use your computer's clipboard.
- **Ask AI:** describe a change for this spot, then press Enter. The AI knows exactly where you clicked.
- **Add text container:** type text and click **Add**. Shift+Enter starts a new line.
- **Add image:** pick a picture. It's added to [My images](/features/tools#my-images-beta) and placed at the line.

If the menu says `Nothing can be added or pasted at this spot`, right-click closer to some text or a picture.

## Ask the AI about one element

For bigger changes, select an element and click **Ask AI** in the editor bar. Describe the change in the box that opens, then choose:

- **Apply with AI** (or press Enter) to make it now, as a new version. Shift+Enter starts a new line.
- **Add to chat** to put the element and your request in the prompt box, so you can add more before sending.

The AI gets the element's exact code and position, so it changes that element and not a look-alike.

Some parts of a page are created by its own code while it runs, so they can't be edited directly. The **Ask AI** box then opens so you can describe the change instead.

## Edit the code yourself

If you know some HTML, CSS or JavaScript, use the **Code** tab. See [Edit the code yourself](/features/live-preview#edit-the-code-yourself).

## Undo any change

Use **Previous version** and **Next version**, or Ctrl+Z, and Ctrl+Y or Ctrl+Shift+Z (⌘Z and ⌘⇧Z on a Mac). To jump further back, open the [history drawer](/features/live-preview#the-history-drawer).

<Tip>
  Mix both ways. Click the page for quick fixes to wording, pictures and order, and use the chat for new features or layouts.
</Tip>
