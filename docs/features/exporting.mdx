Exporting gives you your project as normal files. They work without AppBlips: open them in a browser, send them to someone, or upload them to a web host.

Want it online without downloading anything? Use [Publish](/features/publishing).

## Download a project

<Steps>
  <Step title="Open the project">
    Open it from **My projects**.
  </Step>
  <Step title="Click the download button">
    In the preview toolbar, click the download button, just left of **Publish** (**Update** once the project is published).
  </Step>
  <Step title="Save the file">
    The desktop app asks where to save it. A browser usually puts it in **Downloads**.
  </Step>
</Steps>

What you get depends on the project:

- **One-page app, website or game:** a single `.html` file. Double-click it to open it.
- **Website with several pages:** a `.zip` with one `.html` file per page. Unzip it, then open `index.html`, the home page.
- **App from the Mobile & Web App studio:** a **Download as** menu appears. See [Apps](#apps-html-file-or-react-project).
- **Imported site:** the toolbar has an **Export** button instead. See [Import a site](/features/importing-sites#export-the-project).

Your own pictures from [My images](/features/tools#my-images-beta) and images made with [Pollinations](/features/connectors#pollinations) come along. The same goes for anything your [extensions](/features/connectors) need, such as a form key. If the [SEO tool](/features/tools#seo) is on and has your website address, you also get `sitemap.xml` and `robots.txt`, which makes the download a `.zip`.

## Apps: HTML file or React project

For apps, the **Download as** menu offers two choices:

- **HTML file:** opens in any browser and is ready to upload or share. Pick this if you just want to use or host the app.
- **React project (.zip):** a Vite project for continuing in your own code editor. It needs [Node.js](https://nodejs.org).

To run the React project:

1. Unzip the file and open a terminal in the folder.
2. Run `npm install`.
3. Run `npm run dev` to try it, or `npm run build` to build it for hosting.

## Put your files online

Any host that serves plain files works. Free options:

- **[Publish](/features/publishing)** from inside AppBlips.
- **[Netlify Drop](https://app.netlify.com/drop):** drag your `.html` file or unzipped folder onto the page.
- **[GitHub Pages](https://pages.github.com/)** or **[Cloudflare Pages](https://pages.cloudflare.com/)**, if you want the files in a repository.

## Good to know

- Some pages load code libraries such as React, Tailwind CSS or Phaser from a CDN (a free public server for code). Those pages need an internet connection to open.
- Exported files never contain your AI provider key or the keys AppBlips keeps for Pollinations, Pixabay, Tavily and Surge. They do contain the public values your extensions use, and your Pollinations site key if you chose **My key pays**.
- To back up every project with its version history, use **Settings → Data → Export all apps**. That backup is for restoring into AppBlips, not for hosting.
