# Documentation

Everything you need to publish and run projects on Surge—from your first publish to full automation.

```
$ npm install --global surge
$ surge publish
```

New to Surge? [Get started](https://surge.sh/docs/getting-started)—you'll be live in about a minute.

## [CLI](https://surge.sh/docs/cli/)

The `surge` command line tool—publishing, previews, revisions, domains, teams, and analytics.

## [Guides](https://surge.sh/docs/guides/)

Task-shaped walkthroughs—publish your framework's build, wire up CI previews, migrate from another host.

## [Platform](https://surge.sh/docs/platform/)

The hosted service—custom domains, SSL, clean URLs, client-side routing, redirects, and the CDN.

## [API](https://surge.sh/docs/api/)

The HTTP interface the CLI is built on—tokens, deploys, revisions, DNS, and every endpoint.

## [SDK](https://surge.sh/docs/sdk/)

`surge-sdk`, the JavaScript library behind the CLI—add publishing to your own tools.
